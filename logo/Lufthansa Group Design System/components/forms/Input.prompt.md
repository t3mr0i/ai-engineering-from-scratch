```jsx
<Input label="Email" type="email" icon="ph-envelope" placeholder="you@example.com" />
<Input label="Last name" error="This field is required" />
```

Pass `hint` for helper text, `error` to switch to the error state. Height 48px. Pair with Button in forms.
