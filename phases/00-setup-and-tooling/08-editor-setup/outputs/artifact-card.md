# Editor Setup — reusable artifact

Use this card to apply the lesson outcome outside the walkthrough. Its primary goal is to install VS Code with essential extensions for Python, Jupyter, linting, and remote SSH.

## Executable interface

- **Implementation:** [main.py](../code/main.py)
- **Canonical command (from the lesson directory):** `python3 code/main.py`
- **Controlled variation:** Configure format-on-save, type checking, and notebook output scrolling for AI workflows.
- **Evidence to retain:** the input, output, and invariant needed to set up Remote SSH to edit and debug code on remote GPU machines as if they were local.

## Reuse checklist

- Record the exact command and inputs so another person can reproduce the baseline.
- Change one variable at a time and preserve the before/after evidence.
- Treat the artifact as accepted only when you can evaluate editor alternatives (Cursor, Windsurf, Neovim) and their tradeoffs for AI work.
- Run the lesson tests after adapting the implementation to a new project.
