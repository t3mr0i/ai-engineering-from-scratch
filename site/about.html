About this project

LHIND AI Learning Catalog is a free, open-source curriculum from Lufthansa Industry Solutions that implements every core AI algorithm by hand: 490 lessons across 14 phases, from core AI concepts to autonomous agents, in Python, TypeScript, Rust, and Julia.

Why it exists

Most AI material comes in pieces, and most of it asks you to watch: the hundredth explainer video, someone else's screen, a deploy you copy without understanding. You can finish a playlist and still not be able to explain a loss curve, or wire a tool into an agent without knowing what attention is actually doing inside the model that calls it.

We built this on a different belief: you learn best by doing the work yourself, by reading, solving real exercises, and building the thing. That is how we learned it, and it is the part we enjoyed, so we wrote it down. We wrote and tuned every task list ourselves and aligned them to real learning standards. You write each algorithm from the underlying math first, then run it through the production library to see what the library was doing all along. By the time PyTorch appears, there is nothing mysterious left in it, and each lesson leaves you with something you keep: a prompt, a skill, an agent, or an MCP server.

How it is made

The lessons are authored with AI assistance and reviewed by a human against primary sources. Where a lesson states a fact, it cites the original: an RFC, a spec, or a research paper, not a secondary summary. Corrections are welcome and tracked in the open on GitLab.

The site itself is deliberately plain: hand-written HTML, CSS, and vanilla JavaScript, no framework. A single build script (site/build.js) reads the lesson Markdown in the repository and generates the catalog, search index, sitemap, and llms.txt on every deploy, so the published numbers can never drift from the source. It is hosted on Azure Static Web Apps.

Who builds it

Maintained by Lufthansa Industry Solutions (LHIND) and contributors. It is MIT-licensed and free forever. There is no token, no course upsell, and no gated content.
